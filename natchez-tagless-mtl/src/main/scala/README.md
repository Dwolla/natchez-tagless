# natchez-tagless-mtl sources

natchez integration for `RaiseAspect`, in package `com.dwolla.tracing.mtl`:
`Synthetic[TraceableValue]` and the tracing syntax that interprets a woven
algebra back into `F`.

Populated in milestone **M5**, along with user-facing docs — including the
`@experimental` requirement that Scala 3 derivation imposes on call sites.

See `docs/plans/raise-aspect/`.
