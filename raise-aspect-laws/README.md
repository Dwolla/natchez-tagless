# raise-aspect-laws sources

Law traits and the discipline test kit for `RaiseAspect`, in package
`com.dwolla.tagless.mtl.laws`. Laws L1–L10 are listed in `LAWS.md`, one
directory up.

**This module is frozen.** New test files may be added, but existing laws
must not be weakened, deleted, or modified. If you believe a law is wrong,
stop and raise it rather than editing it.

Follow the conventions in cats-tagless'
[`FunctorKLaws`](https://github.com/typelevel/cats-tagless/blob/v0.16.5/laws/src/main/scala/cats/tagless/laws/FunctorKLaws.scala)/[`FunctorKTests`](https://github.com/typelevel/cats-tagless/blob/v0.16.5/laws/src/main/scala/cats/tagless/laws/discipline/FunctorKTests.scala)
and
[`AspectLaws`](https://github.com/typelevel/cats-tagless/blob/v0.16.5/laws/src/main/scala/cats/tagless/laws/AspectLaws.scala)/[`AspectTests`](https://github.com/typelevel/cats-tagless/blob/v0.16.5/laws/src/main/scala/cats/tagless/laws/discipline/AspectTests.scala).
